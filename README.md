# Get-Out-of-Gandi

An HTML converter that lets you share your Gandi IDE projects more easily on platforms like **itch.io**.

Gandi IDE is an amazing Scratch mod, but sharing projects outside its own ecosystem isn't always straightforward. Until now, getting an embedded project to work in a standalone HTML file has been a bit of a hassle.

**Get-Out-of-Gandi** takes the embed HTML file provided by Gandi IDE and converts it into a new HTML file that opens your project directly in the Cocrea player.

## How to Use

1. Go to your Gandi IDE project page and click **Share**.
2. Open the **Embed** section.
3. Select **Stage Card**.
4. Click the **Download HTML** button at the bottom.
5. Upload the downloaded HTML file to Get-Out-of-Gandi.
6. Convert the file and download your converted HTML.

## Use the Tool

**[Get-Out-of-Gandi](https://inventor702.github.io/Get-Out-of-Gandi/)**

## A Few Things to Know

- The converter runs in your browser and doesn't require you to upload your file to a server.
- The converted HTML file still requires an internet connection to load the project.
- The conversion preserves the rest of the original HTML document while replacing its body with the updated player embed.
